# Developer and Campaign Documentation Refresh

## Goal

Bring the operational developer guide and durable first-playable campaign
design reference in line with the code shipped through the Runic Workshop.

## Scope and authority

The implementation is documentation-only. Source, tests, `Makefile`, and
current delivered plans are the authority; where a design statement is not
implemented, it remains explicitly future scope. Each step is independently
reviewable and uses the regular `docs/refresh-dev-and-game-design` branch.

2. [Refresh the campaign systems reference](02-game-design.md)
